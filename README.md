# TradeWise: Investment Management System

A full-stack Stock Market Trading Platform offering real-time stock data, portfolio & watchlist management, trading contests, and educational resources.

## Overview

TradeWise is a web application built as part of the CS254 Database Management Systems course. It empowers users to track stocks live, manage investments, participate in trading contests, and learn essential stock market concepts — all through a sleek React frontend and a secure Node.js backend.

## Features

* **User Authentication:** Secure login and registration with JWT
* **Real-time Stock Dashboard:** Live prices, interactive charts, and market insights
* **Portfolio & Watchlist:** Track and manage investments and favorite stocks
* **Trading Contests:** Join contests, view leaderboards, and compete with others
* **Educational Resources:** Stock market terminology and FAQs
* **Profile Management:** Update user details and preferences

## Tech Stack

* **Frontend:** React.js, Tailwind CSS, Axios, React Router
* **Backend:** Node.js, Express.js, MySQL, JWT Authentication

## Getting Started

### Prerequisites

* Node.js
* MySQL database

### Installation

1. Clone the repository

```bash
git clone https://github.com/your-username/tradewise.git
```

2. Install backend dependencies

```bash
cd backend
npm install
```

3. Setup MySQL database and update config files
4. Start backend server

```bash
npm start
```

5. Install frontend dependencies

```bash
cd ../frontend
npm install
```

6. Start frontend server

```bash
npm start
```
## Project Structure

* `/frontend` — React app source code
* `/backend` — Node.js API and database integration
